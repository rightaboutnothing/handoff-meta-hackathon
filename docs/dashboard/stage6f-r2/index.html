    Method and interpretation notes

    All figures come from hash-verified local result files. Wilson intervals are derived from the recorded counts.

    PII survivors are per query with any planted value retained. Zero survivors with no usable questions is not successful service.

    Stage 6b operational false blocks include the pending injection layer; available-check detections are a separate series. The methods differ between stages.

    False-block first causes are exclusive. Overlapping layer flags can affect the same query and must not be added.

    Attack blocks include privacy, intent and safety checks, not isolated injection detection. Application completion and full-credit correctness are separate.

    The evaluation frame is known and synthetic variants are correlated. Intervals are descriptive, not future-traffic or compliance certification.

    Meta lens full frozen usability repair target is unmet: 49/50 usable, requested 50. This is separate from the unchanged release gate.

    This view exposes aggregate measurements only. It contains no prompt text, private values, model answers, credentials or request payloads. The synthetic PII sets and known evaluation frame do not establish compliance or guarantee future privacy.
